# 维护指南

发布活动只需两步：复制模板，填写 markdown。

## 一、发布活动

复制 `docs/模板/活动目录名/` 到 `src/activity/new/`，改名、填写、提交。

```
src/activity/new/2026-10-kotlin-share/
  card.md      必需
  detail.md    可选
  signup.md    可选
  back.md      可选
  assets/      可选
```

目录名页面不读，推荐 `年-月-活动短名`，便于查找。

## 二、`card.md`

开头 `---` 之间的部分叫 frontmatter，字段如下。

|    字段    | 必填 |                      写法                      |
|:--------:|:--:|:--------------------------------------------:|
| `title`  | 是  |                     活动名称                     |
| `during` | 是  | 活动起止 `["开始", "结束"]`，如 `2026-10-18T19:00:00+08:00` |
| `enroll` | 否  |                  报名起止，写法同上                   |
| `weight` | 否  |              排序权重，默认 50，大者在前               |
|   `sp`   | 否  |                 跨栏排序，见第五节                  |
| `venue`  | 否  |                   线下地点                    |
| `online` | 否  |            每行 `- ["文字", "链接"]`             |
| `action` | 否  |     按钮 `[文字](链接)`；不填显示「点我报名!」且不跳转      |

阶段由两个时间跨度推算，无需手写：

|      时间       |  阶段  |   时间轴圆点   |
|:-------------:|:----:|:---------:|
|  `enroll` 内   | 报名中  |  向内聚集的涟漪  |
|   报名截止至开场   | 进行中  |    纯圆环    |
|  `during` 内   | 进行中  |  向外发散的涟漪  |
| `during` 之后  | 已结束  |   灰色半透明   |

延期只改 `during`。

## 三、各文件显示在哪

|     文件      |         位置          |
|:-----------:|:-------------------:|
|  `card.md`  |   卡片正面：标题、地点、日期、按钮   |
| `detail.md` |        卡片正文         |
| `recap.md`  | 结束后的回顾，替代 `detail.md` |
| `signup.md` |      报名须知，在正文底部      |
|  `back.md`  |      卡背，右键翻面可见      |

用不到的文件直接删除，页面不留空位。图片、PPT、视频放进 `assets/`，用 `![说明](./assets/文件名)` 引用；视频也可直接写 `<iframe src="..."></iframe>`。

`back.md` 在卡背居中显示，适合题词、落款或协作方 logo；省略时卡背只有渐变。

## 四、活动结束后

无需改字段，页面自动归入历史栏。把目录移到 `src/activity/history/` 仅为归档。

## 五、排序

调大 `weight`（默认 50），大者在前。`sp: true` 让活动跨栏比较：已结束的活动可借此回到最新活动栏，适合公示获奖名单。它停在第一个权重比自己小的活动之前，不保证排第一。

## 六、检查失败

CI 检查必填字段、日期格式与资料引用。失败时看报错行，常见原因是日期格式或文件名不符。本地自查：`node scripts/check-content.mjs`。
